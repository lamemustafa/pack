What changed

The previous version put 370 matrix cells, five recipes, three format chips, two delivery options and four computed-artifact checkboxes on screen at once, in a 400px panel. Every one was added to answer a real problem. Together they were worse than the popup they replaced. That file is kept beside this one as _previous-overbuilt.html.

This version opens with three choices and no button. Everything else still exists, behind Choose periods, for the person who needs it.

Removed outright

  • Four computed-artifact checkboxes. Three read "not built yet". A control for something that does not exist is noise.
  • The delivery choice. More than one file is always a ZIP, because the alternative is one browser dialog per file. The button states it rather than asking.
  • Format chips. Each return has a right default. Formats belong in the custom view, not the first screen.
  • Ten years by default. It opens on the current year; earlier years are one click away.

Unchanged

  • A paused target asks one question with three answers.
  • skipped is terminal and still blocks completion.
  • Every cell is one target with its own binding and download evidence.
